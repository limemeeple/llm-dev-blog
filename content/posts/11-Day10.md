## 간략한 인사시스템 완료
### ERP 개발 시간이 늘어남에 따라 생긴 고민.
ERP에 AI를 접목 시켜보겠다고 시작한 프로젝트인데 오히려 ERP를 만드는데 시간이 더 걸리고 있다.
최대한 메뉴를 줄였는데도 시간이 걸리니 난감한 상황이었다.
그래도 ERP 개발을 계속 진행하는 이유는 이왕 이렇게 만든 김에 초기에 계획했던 AI 기능뿐만 아니라 좀더 확장해서 적용해 볼 예정이다.
그러기 위해서는 여기서 더 메뉴를 만드는게 좋겠다고 판단하고 계속 진행하기로 했다.

### UI는 "빠르고 그럴듯하게"만.. - 디자인에 시간을 뺏기지 말자.
위에서 말했듯이 ERP에 시간을 쏟으면 오히려 주객전도 상황이 되버리기 때문에 UI도 그냥 보기만 좋게 만들기로 결정했다.
그래서 'Ant Design(antd)'를 선택하였는데 ERP,관리자 화면에 맞는 완성품 컴포넌트(테이블, 폼, 모달, 메뉴)가 다 있어서 CSS를 거의 짜지 않아도 업무 시스템 다운 모양이 나오기 때문이다. 특히 테이블 정렬, 페이징이 기본 내장이라 직접 구현할 필요도 없었다.

레이아웃(좌측메뉴 + 상단 헤더 + 본문)은 'shared/components/AppLayout.jsx'에 두었다.
모든 화면이 이 레이아웃 안에 담기므로, 화면을 아무리 추가해도 메뉴, 헤더는 그대로 유지된다.

### 라우팅
상세 페이지를 만들려면 먼저 페이지 간 이동이 필요하므로 React Router를 붙여 주소별로 다른 화면을 매핑했다.
```
/emp/list           ->  사원 목록
/emp/detail/{empId} ->  사원 상세
/emp/form           ->  사원 등록
```

### 조회 계층 구조 - 백엔드와 구조를 맞추다.
이전에 잡은 원칙(pages = Controller, hooks = Service, api = Mapper)을 그대로 따랐다.
사원 상세가 계층을 타고 흐르는 모습은 아래와 같다.
```
EmpDetailPage (조립)
  ├→ useEmpDetail (로직) → getEmpDetail (통신) → 백엔드 /emp/detail
  ├→ useEmpHist   (로직) → getEmpHist   (통신) → 백엔드 /emp/hist
  └→ EmpHistTable (UI 부품)
```
페이지는 두 훅(상세, 이력)을 각각 호출해 데이터를 받고 UI 부품에 넘겨 그린다.
테이블, 폼 같은 UI 조각은 'components'로 분리했다.

### 사원등록과 발령등록 세트 처리.
신규 사원이 등록 되면 두 개의 테이블에 등록 되어야 한다.
emp_mst : 변하지 않는 인사 정보.
emp_hist : 최초 발령 이력.

사원만 등록하고 발령이 없으면 이력 조회 시 두 테이블을 join하기 때문에 목록에 뜨지 않는다.
그래서 이 둘을 '@Transactional'로 묶었다.
```
@Transactional
public void insertEmp(EmpVO empVO) {
    empVO.setEmpStat("S1");            
    empInfoMapper.insertEmp(empVO);   //인사 정보

    EmpHistVO hist = new EmpHistVO();
    hist.setEmpId(empVO.getEmpId());
    hist.setHistStr(empVO.getJoinDt()); 
    ...
    empInfoMapper.insertEmpHist(hist);  // 최초 발령
}
```
두 번째 INSERT(최초 발령)가 실패하면 첫 번째도 자동으로 롤백된다.

### 프론트단 응답 처리 오류
데이터 등록이 완료 된 이후에 보통은 결과값(성공여부)을 보내주도록 만드는데 반환하는 방식을 만들지 않았다는걸 알았다.
프론트 쪽에서 빈 응답을 JSON으로 읽으려다가 에러가 난것이다.
등록은 됐는데 응답처리에서 오류가 발생하여 결과값을 보내주도록 수정해 주었다.

### 잘못했던 내용들
#### Hook 규칙위반.
onClick 안에서 useNavigate()를 호출했다가. **Invalid hook call** 에러가 발생했다.
Hook은 컴포넌트 함수 맨 위에서만 부를 수 있다.
useNaviate는 이동 함수를 만드는 Hook이라 맨 위에서 한번 호출하고 navigate를 받은 다음 클릭 시 받아놓은 nvigate를 실행해야 한다.

#### @RestController 누락
새 컨트롤러에 '@RestController'를 넣지 않는 바람에 404에러가 계속 발생해버렸다.
컨트롤러에 'SYSOUT'을 찍었는데도 나오지 않았다.
어노테이션이 없으면 그 클래스가 빈으로 등록되지 않아 스프링이 주소를 아예 모른다.
값이 안나오고 로그도 안 찍히면 어노테이션 누락을 먼저 의심해야 한다.

### ERP를 테스트에 필요한 메뉴만 만들고 빠르게 AI 개발로 넘어가자.
더 이상은 ERP 만드는데 시간을 소비하고 있을 수 없었다. 그래서 바이브 코딩을 이용해 최대한 빠르게 개발을 종료할 예정이다.
