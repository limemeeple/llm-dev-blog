### unreachable code를 컴파일러가 안 잡아준다.
return 아래에 코드를 더 썼는데 '왜 안 돌지?'라는 질문을 했다.
JAVA면 컴파일 에러로 잡혔을 텐데 파이썬은 조용했다. '분명히 짰는데 안 도는 코드'가 있다면 'return' 위치부터 의심해보면 좋다.

### dict[key] vs dict.get(key)
대괄호 접근은 키가 없으면 **'Nono'**이 아니라 **KEYError**를 던진다.
'없으면 None' 방어코드를 두려면 .get()을 써야 한다.

### fn(**block.input) 언패킹. dict
{"name": "Roland Banks"}를 fn(name="Roland Banks")처럼 키워드 인자로 풀어주는 문법(**)이다. 도구가 이자를 여러 개 받아도 이 한줄로 커버가 가능하다.

### 삼항식 순서가 반대
파이썬은 A if 조건 else B. 자바의 조건 ? A : B와 순서가 다르다.

|자바|파이썬|메모|
|----|----|----|
|{ } 블록|들여쓰기|들여쓰기가 곧 블록|
|;|없음|줄바꿈으로 끝|
|Map<String,Object>|dict|{"role": "user"}|
|List<T> / .add()|list / .append()|대화 이력 쌓기|
|map.get(k) (null 가능)|dict.get(k) (None 가능)|대괄호는 없으면 예외|
|obj.getText()|obj.text|getter 없이 속성 접근|
|null|None|  |
|조건 ? A : B|A if 조건 else B|순서 반대|
|try/catch|try/except|    |
|main()|if __name__ == "__main__":|실행 진입점|
|"a" + b|f"안녕 {b}"|f-string|
|ObjectMapper.writeValueAsString()|json.dumps(x, ensure_ascii=False)|직렬화|
|Map<String, Function> + dispatch|dict + fn = d[name]|전략 패턴|
